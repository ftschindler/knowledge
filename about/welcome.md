This site is the [personal knowledge base (PKB)](https://en.wikipedia.org/wiki/Personal_knowledge_base)
of [Felix Schindler](../docs/people/felix_schindler.md), to be read and written by both people and agents alike.

_This_ is an implementation of the [LLM Wiki pattern](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f),
using [Open Knowledge Format](https://github.com/GoogleCloudPlatform/open-knowledge-format) (OKF) conformal Markdown files
to form an OKF bundle, an [Obsidian](https://obsidian.md/) vault (with embedded [Excalidraw](https://excalidraw.com) diagrams),
and be deployed as a git-backed static site with [MkDocs](https://www.mkdocs.org/).

## How to contribute

The repository supports three equally valid ways of working - pick whichever suits you:

1. **[Edit on GitHub](editing_on_github.md)** - make changes directly in the browser, no local
    setup required.
2. **[Local dev environment](local_dev_environment.md)** - clone the repository, preview with
    `mkdocs serve`, use any text editor.
3. **[Obsidian](using_obsidian.md)** - open the repository as an Obsidian vault with full editing
    UX and inline Excalidraw diagrams.

All workflows follow the same [editing conventions](editing_conventions.md).

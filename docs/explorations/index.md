# Explorations

What I committed to, built on, and then withdrew from. An exploration is not a decision gone
stale. It is work that ran to completion and returned a verdict. Each one is recorded for what it
taught rather than for what it concluded, and none is a current choice.

A finished exploration is `status: stable`, not `deprecated`: nothing about it went out of date,
the work ended. The argument for keeping explorations as their own genre is
[Record an abandoned exploration as an exploration, not a superseded decision](../knowledge_management/record_an_abandoned_exploration_as_an_exploration_not_a_superseded_decision.md).

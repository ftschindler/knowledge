# Explorations

What I committed to, built on, and then withdrew from. An exploration is not a decision gone
stale but a piece of work that ran to completion and returned a verdict, so each is recorded for
what it taught rather than for what it concluded, and none should be read as a current choice.

A finished exploration is `status: stable`, not `deprecated`: nothing about it has gone out of
date, the work simply ended. The argument for keeping them as their own genre is
[Record an abandoned exploration as an exploration, not a superseded decision](../knowledge_management/record_an_abandoned_exploration_as_an_exploration_not_a_superseded_decision.md).

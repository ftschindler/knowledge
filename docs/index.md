# Index

This is the public part of [Felix](people/felix_schindler.md) knowledge base.
Here I note knowledge worth keeping, for people and agents alike.
Each page states one idea and links to the ones it rests on. Follow the links rather than search.

## Sections

Each section defines what it holds and lists what is in it. Sections are ordered by how the ideas build, so reading top to bottom moves from what I care about to what I built.

- [People](people/index.md) - who appears in these notes, and in what capacity
- [Values](values/index.md) - what I care about, ahead of any project
- [Wishes](wishes/index.md) - what I wanted from one thing, where a value is what I want everywhere
- [Principles](principles/index.md) - reusable technical claims I want true in every repository
- [Decisions](decisions/index.md) - what I chose, and the reasoning that got me there
- [Explorations](explorations/index.md) - what I built on and then left, kept for what it taught
- [Blueprints](blueprints/index.md) - the copyable artefact a decision produced
- [Guides](guides/index.md) - a procedure I ran and would run again, with the skippable steps marked
- [Knowledge management](knowledge_management/index.md) - how knowledge gets organised, apart from any tool that stores it
- [Research](research/index.md) - long investigations, recorded as findings rather than conclusions
- [Tools](tools/index.md) - an external tool or project that earns its own page
- [Findings](findings/index.md) - things that cost time once: the symptom, the cause, and the way past it
